# Bellabeat Case Study (Beginner Data Analysis Project)

## About this project
This is a data analysis project where I explored Fitbit fitness tracker data to understand how people use smart devices for activity and sleep.

The goal was to practice Python (Pandas and Matplotlib) and find basic patterns in user behavior.

--

## What I worked on
- Cleaned and organized Fitbit activity and sleep data
- Removed duplicate values
- Created a new column for sleep hours
- Made simple charts using Matplotlib
- Compared activity and sleep patterns

---

## What I found
- Most users spend a lot of time being sedentary
- Some users have short bursts of very high activity
- Average sleep is around 7 hours but varies a lot
- I didn’t find a strong relationship between activity and sleep

---

## Tools I used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

---

## What I learned
- How to clean messy real-world data
- How to create simple visualizations
- How to combine datasets
- How to summarize findings in a clear way
